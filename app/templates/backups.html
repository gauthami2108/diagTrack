Move to another server

Makes DiagTrack read-only and saves one full copy for the new server. On the new server, run setup and choose Move in. Until you retire this server, End move puts everything back as it was.

{% csrf_token %}

Save a full copy

One encrypted file with the database and every attachment, for a USB drive or an off-site copy. It opens only with the backup passphrase.
{% csrf_token %}

Restore the backup of ?

Everything entered after that time is replaced. Staff see a "Back shortly" page for a few minutes and sign in again afterwards. The current database is kept as a fallback until the next restore.

Prepare to move

Retire this server

Only once the new server is running and checked. This server stays read-only for good and stops its scheduled backups. Its data stays on disk.
