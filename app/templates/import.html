How it works

  1. Download the workbook. It already holds everything in DiagTrack, one sheet each for centres, vendors, departments, people and equipment. The first sheet explains every column.
  2. Add or change rows in Excel. New rows go at the bottom. An empty cell leaves the current value alone. To retire something, set Active to No.
  3. Upload it here. DiagTrack checks every row and shows what will be added and changed, and any rows to fix. Nothing is saved yet.
  4. Press Import. Everything is saved together. New people without a password get one, shown once.
